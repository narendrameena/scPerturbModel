What your atlas can actually resolve

A context × perturbation interaction is estimated as a covariance between independent replicates. Its precision is set by the number of replicate pairs — and cells never enter that count. Every line is one cross-replicate pair. At one replicate there are no lines at all — the estimator has nothing to correlate, and no amount of sequencing depth creates a pair. This is why replication, not cell count, is the binding constraint.

Where a fixed cell budget should go

Cells enter only through per-condition noise, which saturates; replicates enter through the pair count, which does not. Splitting a fixed budget more ways therefore wins until the per-condition measurement gets too shallow to be worth pseudobulking.

How this is computed

The interaction is estimated as a covariance between independent replicates, so noise contributes zero in expectation and precision comes from averaging over pairs. For c contexts, p replicated perturbations and r replicates, the pair count is c·p·r(r−1)/2. Averaging F ≈ 2000 weakly dependent features adds a further 1/√F, giving a standard error of (1 + 1/snr²)/√(pairs·F) and a detection floor of 1.96× that.

Cells appear nowhere in that expression. They act only on snr, and that dependence saturates: subsampling Tahoe‑100M to 2% of its cells retained 92% of a known MEK×MAPK interaction, while cutting to 10% of contexts collapsed precision to a spread of 0.084 against an effect of 0.10.

Validated on five published atlases — Tahoe‑100M, LINCS phase 1, OP3, sci‑Plex 3, Spear‑ATAC — using one shared noise constant and no per-atlas tuning. It calls all five correctly for any snr between 0.10 and 0.30, a threefold range. Five free parameters fitting five binary outcomes would prove nothing, so there are none.

Two limits worth stating. The field survey counts replicate structure recoverable from deposited metadata, not what was run at the bench — harmonisation may have dropped annotation an experiment had. And the budget table's noise-saturation curve has two assumed parameters; swept over a fortyfold range the optimum is never one replicate, but its exact value moves.

Run it locally

pip install -e .

perturbdesign plan --contexts 48 --perturbations 1100 --replicates 2 \
                  --replicated-fraction 0.135 --target 0.005
perturbdesign audit atlas.h5ad
perturbdesign budget --cells 95600000 --contexts 48 --perturbations 1100

audit reads an .h5ad directly and reports which obs columns it used, so a design can be checked against the object that will actually be released.
